# 教程截图

把每一步的截图按以下文件名放进本目录（PNG，建议宽 ≥1200px）：

- `step1.png` — Violentmonkey 安装页
- `step2.png` — Greasy Fork 脚本页（「安装此脚本」按钮）
- `step3.png` — 「我看过的电影」列表页
- `step4.png` — 列表页自动出现的「书影音游戏汇总」浮窗
- `step5.png` — 导出弹窗（勾选「同时导出海报/封面资源」）
- `step6.png` — 抓取完成后的「下载封面 ZIP」

缺失的截图在页面上自动隐藏（`onerror` 隐藏 figure），不影响文字教程展示。
